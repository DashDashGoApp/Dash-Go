# =====================================================================
# Dash-Go Raspberry Pi display reference (not applied by the installer)
# =====================================================================
#
# Dash-Go preserves the operating system's display configuration. On
# Raspberry Pi OS Bookworm and Trixie, keep the modern KMS driver selected by
# the OS. This file is a reference only; the installer never copies it into
# /boot and never changes dtoverlay or gpu_mem automatically.
#
# If manual troubleshooting is truly necessary, first create a backup through
# ~/install.sh, then follow Raspberry Pi OS documentation for the installed
# release. Dashboard Doctor reports a legacy Dash-Go FKMS override when one
# is found on Bookworm or Trixie.
#
# Typical modern KMS baseline (do not paste blindly over a working config):
# dtoverlay=vc4-kms-v3d
# max_framebuffers=2
#
# Leave gpu_mem at the operating system default unless a device-specific
# Raspberry Pi troubleshooting guide calls for another value. Modern Pi OS
# images generally manage display memory without a Dash-Go override.
# =====================================================================
